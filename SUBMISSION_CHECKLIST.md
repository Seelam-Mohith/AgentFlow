# Submission checklist

- [x] Source code for Next.js frontend, FastAPI backend, and real Python CLI worker
- [x] Approved tool registry and validated arguments
- [x] Real HTTP crawling, HTML extraction, robots policy, page/depth limits
- [x] SSRF checks, pinned IP requests, safe redirects, disabled environment proxies
- [x] stdout/stderr capture, exit code, deadlines, output limits, process cancellation
- [x] Pydantic intent and output validation
- [x] Optional OpenAI integration and usable no-key fallback
- [x] Chat, progress, result tabs, JSON export, history, rerun, settings, themes
- [x] Deterministic tests and opt-in live public-site integration test
- [x] README with exact install/run/test commands and architecture diagram
- [x] `.env.example` with placeholders; no real keys committed
- [x] Dockerfiles and Compose configuration supplied
- [x] 3–5 minute demonstration recording script
- [ ] Record and review the actual demonstration video
- [ ] Supply the recorded video link to judges
- [ ] Optional deployment (no deployed URL claimed)
- [ ] Verify Docker on a Docker-enabled host
- [ ] Verify OpenAI mode with an account API key

Actual build/browser verification status is recorded in `VERIFICATION.md`. A checked implementation item means the code is present; test results and remaining environmental limits must be assessed separately.
